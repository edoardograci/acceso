# Acceso

Acceso is an Astro-based platform for discovery and reference of independent design studios, objects, and projects.

## Project Structure

- `src/`: The source code for the Astro application.
  - `components/`: Reusable UI components.
  - `layouts/`: Page layouts.
  - `pages/`: Site pages (Astro and Markdown).
  - `styles/`: Global styles and CSS variables.
- `public/`: Static assets like images, icons, and fonts.
- `scripts/`: Automation scripts for data generation and migration.

## Tech Stack

- **Framework**: Astro
- **Database**: Turso (SQLite)
- **Deployment**: Cloudflare Pages
- **Analytics**: PostHog
